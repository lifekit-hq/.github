# Support

- **Bug or feature request?** Open an issue on the relevant repository using its
  issue templates.
- **Question about how something works?** Open a discussion or an issue on the repo
  closest to the topic; `lifekit-stack` is the right place for stack-wide questions.
- **Security problem?** Never a public issue - see [SECURITY.md](SECURITY.md).

This is a personal open-source stack maintained by one person; responses are
best-effort, usually within a few days.
